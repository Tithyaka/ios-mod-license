 1. HOW IT WORKS
================================================================================

ROSVIP.dylib loads
  └─ Constructor fires (+2 sec, after UIWindow ready)
       └─ LicenseGuard checks saved key in Keychain
            ├─ KEY EXISTS & VALID  →  "🔓 RoS VIP — Active" dialog
            │      Shows: Key Type, Activated date, Exact Expire Date+Time,
            │             Time Remaining → tap "▶ Continue to Game"
            │
            └─ NO KEY / EXPIRED / WRONG DEVICE →  "🔐 RoS VIP Activation"
                   Shows: Your Device ID (HWID), e.g. A8B2-C4F1
                   Buttons:  [✅ Activate]  [📋 Copy Device ID]  [✕ Cancel]
                   On Cancel → exit(0) immediately

================================================================================
 2. KEY FORMATS
================================================================================

  SHORT HWID KEY (device-locked, generated by KeyGenGUI.exe):
    ROSVIP-7D-A8B2-C4F1-1FC3
    └─ Only activates on the device with HWID A8B2-C4F1

  SIGNED FULL KEY (generated by license_gen.py):
    ROSVIP-LIFE-<base64_payload>.<base64_signature>
    └─ Valid on any device (no HWID lock in this format)
    └─ You can add hwid field to payload to lock it per-device

  Duration Tags:
    1D   = 1 Day          (86,400 seconds)
    7D   = 7 Days         (604,800 seconds)
    30D  = 30 Days        (2,592,000 seconds)
    90D  = 90 Days        (7,776,000 seconds)
    365D = 365 Days       (31,536,000 seconds)
    LIFE = Lifetime       (expires_at = 0)

================================================================================
 3. GENERATING KEYS FOR CUSTOMERS
================================================================================

  Step 1 → Customer opens game, sees HWID in activation dialog
  Step 2 → Customer taps [📋 Copy Device ID] → sends you e.g. A8B2-C4F1
  Step 3 → Open KeyGenGUI.exe  (or run: python license_gen.py)
  Step 4 → Paste their Device ID, choose duration, click Generate
  Step 5 → Send them: ROSVIP-7D-A8B2-C4F1-XXXX

  CLI shortcut (no HWID lock, all devices):
    python license_gen.py 7D
    python license_gen.py 30D
    python license_gen.py LIFE

================================================================================
 5. INJECTING INTO YOUR IPA
================================================================================

  Files needed (inject BOTH into the IPA):
    • ROSVIP.dylib        — your game mod
    • LicenseGuard.dylib  — offline license verifier (new build required)

  Using Sideloadly / ESign / TrollStore / Azule:
    1. Inject ROSVIP.dylib into the game binary
    2. Drop LicenseGuard.dylib into the app's Frameworks/ folder
    3. ROSVIP.dylib links to LicenseGuard.dylib via @rpath/LicenseGuard.dylib

  ⚠  You MUST recompile LicenseGuard.dylib from source (license_system/)
     to embed the ROSVIP-iOS-v1 product ID and your Ed25519 public key.

================================================================================
 6. BUILDING LicenseGuard.dylib
================================================================================

  On a macOS machine with Xcode installed:

    cd license_system/
    python license_gen.py   # run once to generate/verify public_key.h
    chmod +x build.sh
    ./build.sh

  Output:
    LicenseGuard.dylib              → iOS ARM64 (primary)
    LicenseGuard-iOS-arm64.dylib    → iOS ARM64 (copy)
    LicenseGuard-macOS-universal.dylib → macOS ARM64 + x86_64

  Or push to GitHub — the Actions workflow builds it automatically.
